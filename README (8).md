# Data

The dataset is **not** committed to this repository. Download it and place the CSV here:

```
heart-failure-prediction/data/heart_failure_clinical_records_dataset.csv
```

- Source: https://www.kaggle.com/datasets/andrewmvd/heart-failure-clinical-data
- Size: 299 rows, 13 columns, no missing values
- Target column: `DEATH_EVENT`

Check the dataset's licence on its source page before redistributing it.
